## 🇨🇳 中文

它回答的不是「怎么写」，而是「写什么」。先把商业背景、客户研究、现状与竞品格局一次性吃全，再把每个 idea 分成 searchable（捕捉搜索存量需求）或 shareable（制造传播与讨论）。每个候选话题会被映射到认知 / 考虑 / 决策 / 实施四个购买阶段，并按客户影响 40% + 内容市场契合 30% + 搜索潜力 20% + 资源 10% 逐条打分排序。最终产出内容支柱、优先话题表和话题簇地图，可直接落成一份策略文档。

### ✨ 能做什么

- 一次打包问齐商业、客户研究、现状、竞品四类上下文，不逐条挤牙膏
- 每个 idea 标注 searchable 或 shareable，并映射到认知 / 考虑 / 决策 / 实施四个购买阶段
- 40/30/20/10 四维打分：输出每个话题的实际分数与总分表
- 把高分 idea 聚成 3-5 个内容支柱，附选择理由与子话题簇
- 产出优先话题表：标题、内容类型、目标关键词、购买阶段、为什么选它
- 可选加出关键词簇 CSV、季度编辑日历、专家外联 wishlist

## 🇬🇧 English

It answers what to write, not how to write it. Business background, customer research, current content performance and the competitive gap are gathered first, then every idea is classified as searchable (capturing existing demand) or shareable (creating demand). Each candidate maps to one of four buying stages, awareness through implementation, and is scored 40% customer impact, 30% content-market fit, 20% search potential, 10% resources. The output is content pillars, a prioritised topic table and a topic cluster map, saved as a strategy document.

### ✨ What it does

- Gathers business, customer, status-quo and competitor context in one batched question round
- Tags each idea searchable or shareable and maps it to awareness, consideration, decision or implementation
- Scores every topic 40% customer impact / 30% content-market fit / 20% search / 10% resources
- Clusters the winners into 3-5 content pillars with reasons and subtopic clusters
- Outputs a priority topic table with target keyword, content type, buying stage and rationale
- Optional extras: keyword-cluster CSV, quarterly editorial calendar, expert outreach wishlist
